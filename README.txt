GESTÃO DE DOAÇÕES - VERSÃO FINAL
Projeto Extensionista - Sistema Web

Arquivos:
- index.html: telas e estrutura do sistema.
- style.css: visual e responsividade.
- script.js: funcionalidades e armazenamento.
- README.txt: instruções.

Funcionalidades:
- Cadastro, pesquisa, edição e exclusão de doadores.
- Contagem de doações por doador.
- Doador selecionado a partir do cadastro.
- Registro de doações recebidas com quantidade, unidade e data.
- Controle automático do estoque.
- Produtos tratados sem diferença entre maiúsculas e minúsculas.
- Unidades vinculadas ao produto.
- Aviso de estoque baixo.
- Registro de entregas para famílias.
- Bloqueio de entrega acima do estoque disponível.
- Histórico de entradas e saídas.
- Exclusão de movimentações com ajuste do estoque quando possível.
- Dashboard inicial.
- Relatórios por produto.
- Pesquisas nas listas.
- Mensagens discretas de sucesso/erro.
- Layout responsivo para telas menores.
